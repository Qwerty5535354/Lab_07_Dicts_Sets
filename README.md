# Лабораторна робота № 7. Словники і множини

**Варіант 5. Населення міст.**

## Мета

Навчитися працювати зі словниками (`dict`) і множинами (`set`).

## Завдання

1. Словник «місто: населення»: вивести місто з найбільшим населенням, додати нове місто, вивести всі міста з населенням понад введене значення.
2. Множини міст двох туристів: знайти спільні міста, міста лише першого туриста та всі унікальні міста.

## Теорія

* Словник зберігає пари «ключ: значення»; пошук ключа працює швидко. `max(cities, key=cities.get)` повертає ключ із найбільшим значенням, `name in cities` перевіряє наявність ключа.
* Множина зберігає лише унікальні елементи. Перетин `a & b` — спільні, різниця `a - b` — лише з першої, об'єднання `a | b` — усі унікальні.
* Початкові дані (6 міст у словнику, по 6 міст у кожній множині) задані в програмі; населення — округлені навчальні значення.
* «Понад» означає строго більше. Регістр у назвах міст враховується.

## Запуск

Потрібен Python 3.10+ (перевірка: `python --version`). Сторонні бібліотеки не потрібні.

```bash
python main.py
```
